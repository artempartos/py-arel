## Quick Start

### Usage Example (goal)

```python
from arel import Table, sql

# Create tables
users = Table('users')
posts = Table('posts')

# Simple SELECT
query = (users
    .project(users['name'], users['email'])
    .where(users['active'].eq(True))
    .order(users['created_at'].desc())
    .take(10))

# SELECT with JOIN
query = (users
    .project(users['name'], posts['title'])
    .join(posts)
    .on(posts['user_id'].eq(users['id']))
    .where(users['active'].eq(True)))

# Aggregation
query = (users
    .project(users['country'], users['id'].count())
    .group(users['country'])
    .having(users['id'].count().gt(10)))

# Window functions
query = (users
    .project(
        users['name'],
        users['salary'].sum().over(
            Window().partition(users['department'])
        ).as_('dept_total')
    ))

# Get SQL
sql_string = query.to_sql(engine)
```

## Main Differences from Ruby API

| Ruby | Python | Reason |
|------|--------|---------|
| `or` | `or_` | `or` is a reserved word |
| `and` | `and_` | `and` is a reserved word |
| `not` | `not_` | `not` is a reserved word |
| `in` | `in_` | `in` is a reserved word |
| `from` | `from_` | `from` is a reserved word |
| `True` node | `True_` | `True` is a reserved word |
| `False` node | `False_` | `False` is a reserved word |
| `equality?` | `is_equality()` | Python doesn't support `?` in names |
| `ascending?` | `is_ascending()` | Python doesn't support `?` in names |
